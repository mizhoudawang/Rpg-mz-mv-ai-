AI NPC 配置面板 —— 怎么打开
================================================

四种方式，任选一种：

  1) 游戏里按 F10
       最省事，随时可用，不用找菜单。

  2) 游戏里按 Esc 打开菜单
       菜单 -> 「AI 角色」-> 第一项「⚙ 打开配置面板」

  3) 双击游戏根目录（和 Game.exe 放一起）的「打开AI配置面板.bat」

  4) 万一上面三种都不行：菜单 -> 「AI 角色」-> 第二项「🔑 直接填 API Key」
       不弹新窗口、不联网，直接在游戏画面上填 Endpoint / 模型 / Key / 温度。


面板能改什么
------------------------------------------------
  · 服务商一键切换（DeepSeek / OpenAI / 通义千问 / 智谱 / 月之暗面 / 硅基流动 / 本地 Ollama）
  · API Key、模型名、Endpoint
  · 测试连接（真实发一次请求，失败会把服务端原文错误贴出来）
  · 拉取该服务商的模型列表
  · 对话行为 / 讲价区间 / 偷窃抢劫开关等全部参数
  · 「仿真模式」开关：没有 Key 也能先试玩，验证链路是否通

保存之后不用重启游戏 —— 下次和 NPC 搭话时会自动读取新配置。


双击 .bat 会发生什么
------------------------------------------------
  电脑上装了 Node.js  ->  起一个只监听 127.0.0.1 的小服务，浏览器自动打开，
                          改完直接写回 config.json，还能联网测试连接。
  没装 Node.js        ->  直接用浏览器打开面板。这时需要手动操作：
                          点「导入 config.json」选中本目录的文件，
                          改完点「保存配置」。
                          Edge / Chrome 会直接写回原文件；
                          其它浏览器会改成下载，把下载到的 config.json
                          覆盖回本目录即可。

  什么都不装也行：直接用记事本打开本目录下的 config.json，
  把 "apiKey": "" 的引号里填上你的 Key，保存即可。


出问题看哪
------------------------------------------------
  本目录下的 startup.log —— 插件每次启动都会写一份自检：
    · 插件有没有加载成功
    · 菜单项「AI 角色」有没有注册
    · config.json 有没有读到、从哪读的
    · 有没有 JS 报错（未捕获错误会一并记进去）

  想要更详细的日志：把 config.json 里的 "debug" 改成 true。

  ── 顺便说一句：这个 .bat 的内容全是英文，不是偷懒。
     Windows 的 cmd.exe 在 chcp 之后解析含中文的 .bat 会按字节错位，
     把后面的命令行切坏（实测：'ho' is not recognized...）。
     所以中文说明都放在这个 txt 里，用 type 打印，不会被解析。
